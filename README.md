# Handwritten Digit Recognition

A beginner-friendly machine learning project that recognizes handwritten digits (0–9) using Python and Scikit-learn.

## Technologies
- Python
- Scikit-learn
- Matplotlib

## How to Run
1. Install dependencies: `python3 -m pip install scikit-learn matplotlib`
2. Run: `python3 main.py`

## Attribution
Based on the official Scikit-learn handwritten digits classification example.
